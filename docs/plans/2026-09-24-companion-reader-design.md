# RTR4 伴读工作台设计

日期：2026-09-24。用户已选择「伴读模式／方案 A」，本文件细化该方向；本次仅设计规划，未实现以下功能。

## 1. 产品目标与范围

用户阅读原书时，能知道当前内容在解决什么问题、公式为什么成立、代码如何对应，并能用一个小问题检查理解。原书是主线，伴读是帮助，不强制完成课程才能翻页。

第一轮范围：第五章 PDF 104–154 页阅读，精讲统一已有 5.1、5.2、5.2.2；先以平方反比衰减完成纵向样板，再迁移其余已有知识点。不新增模型、在线服务或本地 Shader 运行环境，不承诺第五章或整本书精讲全部完成。

## 2. 从现状发现的问题

- App.tsx 分别维护 page、sectionSlug、selectedBlockId：手动翻页保留旧课程，点击来源只在已加载课程内匹配知识点，跨课程同步不完整。
- KnowledgeLessonPanel 的选点以 primary_source_id 跳转，但第一张卡可能引用别页。例如平方反比选中 p111 公式，首卡却讲 p110 图；卡片上下步也不更新原书。
- 5.1、5.2 是七段摘要，5.2.2 是一至两张短卡；缺少符号解释、假设、推导中间步骤、反例和可检查的答案。
- 学习进度只有“标记已掌握”，无法区分阅读、自我判断与实际验证；Lesson.questions 存在但前端没有使用。
- BlockOverlay 默认给所有块加框并覆盖底层；页眉页脚也获得按钮，视觉与键盘噪声大。
- PdfReader 只有适宽 Canvas，无用户缩放、文本选择层、阅读位置恢复；大书需限制同时渲染页数。
- 图片引用只显示按钮，Shader 独立堆在章节末尾，问答实际是章节检索而非理解当前段落的教师。

## 3. 信息架构

桌面布局示意（非最终视觉稿）：

```text
┌ RTR4 · 第五章  [目录]          [继续上次阅读] [专注原书] ┐
│ PDF 原书 · 约 60%             │ 当前页伴读 · 约 40%      │
│ [上页] PDF 110 [下页] [缩放]  │ 本页要解决：光为何变暗？ │
│                              │ 本页知识点（可选择）     │
│         原始页面             │ 直觉解释 + 原图/公式卡   │
│  悬停/选中才出现来源高亮      │ [展开推导与符号解释]     │
│                              │ [检查理解] [实践验证]    │
│                              │ [查找书中相关内容]       │
└──────────────────────────────┴──────────────────────────┘
```

- 两栏比例可调整，提供键盘方式；右栏有最小可读宽度。专注原书可一键收起右栏，并可恢复。
- 顶栏紧凑；章节目录折叠，显示“有精讲／可阅读，暂无精讲”，不用一排课程按钮占空间。
- 阅读采用单页翻页加缩放，先不做无限滚动。工具条固定，两栏独立滚动；小屏改为原书／伴读切换，保持同一位置。
- PDF 页码始终明确标注；书内印刷页码仅在核实映射后显示，不猜固定偏移量。
- 默认显示一段完整的直觉解释和一个关键证据，不把每句话拆成必须点击的幻灯片。深推导、练习、实验逐层展开。

## 4. 同步与返回规则（核心）

阅读位置是主状态，但“查看旁证”不等于“开始读另一个知识点”。使用显式事件更新，禁止两个 useEffect 相互驱动造成来回跳转。

| 操作 | PDF | 伴读 |
| --- | --- | --- |
| 翻页、输入页码、目录跳转 | 到目标页，滚至页顶 | 跟随新页；列出本页知识点。当前点若仍关联此页则保留，否则选本页首项 |
| 点击公式／图／段落 | 保留页码，突出所选块 | 按引用映射选点；无精讲则显示原文证据与暂无讲解提示 |
| 同页多个知识点 | 不擅自换页 | 列出候选，点击才切换；不通过滚动位置猜用户意图 |
| 展开推导、查看答案 | 不动 | 只展开内容，避免干扰阅读 |
| 点击“在原书查看” | 跳到引用并定位 | 固定当前知识点，显示“正在查看旁证／返回阅读位置” |
| 返回阅读位置 | 恢复进入旁证前的页与滚动位置 | 恢复原知识点；连续引用只保留一个返回锚点 |
| 旁证期间主动翻页 | 到新页，结束旁证状态 | 恢复自动跟随新页 |
| 没有精讲的页／块 | 正常阅读、缩放 | 不显示无关旧课程；可以看原文、检索、打开目录 |

页到知识点映射从已验证的引用块派生，匹配 point.citations 和 card.citations，并纳入新增结构化引用；不使用粗略章节范围代替精确映射。跨页知识点可在多页出现。

## 5. 精讲内容标准

每个知识点至少具备以下内容；“更细”意味着补全推理，而不是把摘要写长。

1. **阅读目标**：学完能解释或计算什么；列出必要前置知识，用可展开补充代替打断。
2. **直觉与原书证据**：一句核心结论、一个图／公式／段落锚点，解释读图时看哪里。标明原书内容、教学补充、工程近似。
3. **推导与符号**：符号含义、单位、方向约定、适用假设；按因果关系推导，给出数字代入和边界情形。公式原文与教学简化分开展示。
4. **检查理解**：先提问，再由用户展开提示和答案；给错误选项的原因。结果是自测记录，不宣称自动证明“掌握”。
5. **实现与实验**：关键代码与公式逐项对应；明确改哪一项、先预测什么、预期观察是什么、出现偏差检查哪里。不是每一点都强制配 Shader。

### 样板：平方反比衰减（待逐页复核后出版）

- 目标：解释为什么是 1/r² 而不是 1/r，能算出距离翻倍的相对变化。
- 证据：图 5.5（PDF 110）与公式 5.11（PDF 111）。默认在用户当前页解释，查看另一页属于旁证。
- 教学补充：在均匀、各向同性点源且无吸收的理想条件下，总通量分布在面积 4πr² 上；比较相同朝向的小接收面，得到相对因子 (r₀/r)²。表面倾角的余弦因素另行讨论，不混作距离效应。
- 数字例子：r/r₀ 为 1、2、4 时相对值为 1、1/4、1/16。区分入射能量数值与经过曝光、色调映射后的屏幕亮度。
- 自测：距离从 2 变为 6，其他条件不变，比例是多少？答案 1/9；1/3 是漏掉面积平方。
- 工程边界：r=0 的奇点说明理想点源模型的局限；epsilon 和有限范围窗函数是工程近似，不冒充原物理定律。
- Shader 实验：提供隔离距离因素的代码或参数，固定方向和材质；禁止用同时改变方向、距离的鼠标拖动来宣称验证平方规律。数值规律用表格核对，画面仅观察趋势。

### 内容质量约束

- 现有聚光灯“本影／半影”名称、内外角顺序以及示例 smoothstep 与原书公式的差异必须对照原书复核，不直接复制旧措辞。
- 所有图、公式可回到具体页和块；来源存在不等于论证正确，需人工逐项核对。
- 5.1、5.2 转成与 5.2.2 一致的知识点结构；保留旧 sections 兼容接口，不继续维护两套可见教学正文。

## 6. 原书与证据展示

- 证据卡按图、公式、段落区分：图使用已存在的可安全提供的局部图像；公式用核验 LaTeX 并保留原页定位；段落用短摘录与讲解，不大段复制原书。
- 优先复用现有页图与裁剪能力；若没有安全图像接口，增设只接受书籍与来源块 ID 的接口，由服务端解析可信路径。绝不让前端传任意本地路径。
- 无图像时仍提供可用原书定位与明确提示，不伪造占位解释图。不向第三方传原书。
- 来源框默认静默，悬停、键盘聚焦或选中时显示。过滤页眉页脚；可开启“显示全部定位框”。
- 引用跳转不止改变页码：目标块应滚入可视区。缩放和调整分栏后高亮仍与原文对齐。
- 加载／解析失败分开处理：伴读数据失败不能阻止读 PDF。提供本区域重试；不无限重试或重下载整书。

## 7. 练习、问答、进度

- 右侧默认是伴读，不是空聊天框。次要入口命名“查找书中相关内容”，明确当前为第五章本地检索摘录。
- 当前术语可预填检索问题，但发送前让用户看到文本；未实现页级过滤前不声称限定当前页。
- Shader 留在外部 ShaderToy：一键复制、中文运行步骤、所需 channel 说明、预期现象；复制失败提供手选代码。链接不会自动载入代码，不自动上传原书。
- 本地保存阅读页、知识点、展开区域和版面偏好。存储 key 包含书籍／内容版本；旧知识点 ID 失效时回退到有效页。暂不做云账户和同步。
- 区分“已阅读”“待复习”“自测通过（自评）”，可撤销。现有已掌握标记迁移为自评记录，不转成客观测验分数。
- 首次进入简短提示；再次进入直接恢复。打开目录、看证据或外部示例后都应能继续原阅读。

## 8. 技术方案与边界

保留 React、PDF.js、FastAPI 和本地内容文件。新增纯函数阅读状态机与引用索引，集中在 App 层协调；LessonPanel 负责加载展示，不反向隐式切换 PDF。只加载少量现有课程元数据和当前页引用，不预渲染全书。

数据结构在 teaching.py 和 types.ts 同步扩展：知识点目标、前置项、符号、推导、自测、实践、内容性质与引用。旧 JSON 可读取，新伴读发布需通过内容完整性校验。自测用确定的提示／参考答案，不新增 LLM 评卷。

保留 Range 与 SHA-256 校验，不更换 PDF 管线；文本选择层、全书搜索、无限滚动、多书管理、生成式教师作为后续独立议题，不混入本轮。

## 9. 实施次序与验收

1. 同步状态与引用映射：用测试覆盖翻页、同页多点、跨页旁证、无讲解页、异步响应过期。
2. 平方反比纵向样板：原书、解释、证据、自测、实践完整可走通，再评审信息密度。
3. 阅读界面：缩放、分栏、静默高亮、精确定位、窄屏与键盘操作。
4. 迁移已有 5.1、5.2、5.2.2 内容，逐页审校，保留显式未覆盖范围。
5. 本地恢复、问答入口、外部实践；完整回归、浏览器验收、分步提交与上传。

验收场景：在 p110 阅读图 5.5 → 获得对应直觉解释 → 查看 p111 公式且讲解不跳走 → 返回原页 → 回答 2→6 的自测 → 打开 ShaderToy 指引 → 刷新继续阅读。随后到未覆盖页，右侧不得保留错误精讲。

质量门槛：原有测试、构建和章节检索评测不回退；引用有效率 100%；所有首轮知识点符合上述内容标准；大 PDF 单文档复用、当前页渲染、过期请求取消。记录首载/翻页耗时和内存趋势，与改动前同机基线比较，不凭未测数字承诺性能。

## 10. 本轮不做

不新增模型下载，不做本地 Shader 引擎，不为美化迁移 UI 框架，不假装检索就是 AI 教师，不用“点击完成”代替掌握验证，不一次性批量生成整本书精讲。
