# 全书伴读工作区交互设计

状态：用户已确认交互方向；本文件为实施规格，功能尚未实现。

## 定位与范围

隶属于 2026-09-28-whole-book-roadmap.md 的伴读模块，适用于全书，不以第五章或某个课程 ID 为布局条件。首批实现侧栏收展、独立阅读位置、窄屏切换；后续接入通用课程目录和分层讲解。保留现有 React/PDF.js/FastAPI，不新增 UI 框架、模型或 Shader 引擎。

本设计不是重写教学流水线。完整目录、章节发布、图像审校和跨章概念关系仍依全书路线推进；缺少数据时如实显示，不通过页码范围猜知识点。

## 1. 页面信息结构

```text
┌ 书名 · 当前位置   [目录]                  [收起伴读/展开伴读] ┐
│ 原书工具：上页 / 页码 / 下页 / 缩放  │ 当前页伴读 · [收起]    │
│                                    │ 阅读目标与核心解释     │
│            原始 PDF                │ ▸ 公式与推导           │
│                                    │ ▸ 图片详解             │
│                                    │ ▸ 例子与实践           │
│                                    │ ▸ 检查理解             │
│                                    │ [查找相关内容]         │
└────────────────────────────────────┴────────────────────────┘
```

顶栏只放当前位置和全局操作，去掉长期占位的宣传文案。页码始终说明是 PDF 页码，印刷页码仅在映射已核验时显示。目录与精讲状态分开，不将“章节已登记”表达为“精讲已完成”。

侧栏默认打开、宽度初值约40%；用户可收起。关闭后 PDF 容器占满可用区域，页面在适宽模式下重新计算尺寸；手动缩放时保持缩放比例并居中，不无条件把文字放大到整屏。

## 2. 三种展示状态

| 状态 | 主体 | 入口与行为 |
| --- | --- | --- |
| 宽屏伴读 | PDF 与侧栏并排 | 顶部和侧栏均可收起；两栏独立滚动 |
| 宽屏专注 | PDF 单栏 | 顶部持续保留“展开伴读”，不留空白右栏 |
| 窄屏 | 原书／伴读二选一 | 顶部两个有明确选中状态的切换按钮，保留两边位置 |

以工作区实际宽度判断布局，不判断设备种类。初始断点设为960 CSS px，原书最小宽480、侧栏最小宽320；分隔条与内边距计入可用空间。浏览器200%缩放应自然进入窄屏。断点以实机验收结果调整。

宽屏比例可在满足最小宽度时调整；鼠标/触摸拖动与键盘均可操作。分隔条使用可聚焦 separator，左右键每次调整2%，Home恢复默认。拖动时合并尺寸更新，结束后保存，避免每个像素都触发昂贵渲染。

从宽屏进入窄屏默认保留原书；用户主动选过的窄屏面板在本会话内记忆。回到宽屏恢复宽屏侧栏偏好，不能因手机看过伴读而覆盖桌面“收起”设置。

## 3. 收展与状态保持

| 事件 | 应发生 | 不应发生 |
| --- | --- | --- |
| 收起侧栏 | 保存侧栏滚动位置；空间交还原书；焦点回展开按钮 | 卸载文档、清空回答草稿、重置学习卡 |
| 展开侧栏 | 恢复宽度和当前知识点的展开状态 | 把PDF跳回页顶、回到默认第五章 |
| 主动翻页 | 更新当前页内容；同一知识点跨页保留展开项 | 自动打开用户已收起的侧栏 |
| 关闭侧栏时选中区域 | 选中高亮，显示显式“解释此处”操作 | 强行弹出侧栏 |
| 点击“解释此处” | 打开侧栏或切到窄屏伴读 | 清掉原书位置 |
| 点击原书引用 | 展示目标区域，保持当前讲解；提供返回 | 通过页码同步effect把讲解切走 |
| 点击返回 | 恢复原页、阅读锚点和讲解 | 建立不可退出的跳转循环 |

侧栏收起时保持当前组件实例或把可编辑状态提升到父层；隐藏内容必须退出焦点顺序和无障碍树。只保留当前课程实例，不为了保存状态缓存所有章节DOM。

原书只开一个 PDFDocument；隐藏不能 destroy。变化中的页面渲染允许取消和合并，旧请求不得覆盖新页。

## 4. 阅读位置算法

不只保存 scrollTop：适宽重排后同一像素不代表同一段原文。

- 布局变化前记录页码和视窗顶部相对页框的归一化位置，必要时同时记录水平位置。
- 适宽模式：尺寸更新且新 render 完成后，按页框新高度恢复锚点并限制在合法滚动范围。
- 手动缩放：保持用户倍率；发生缩放操作时以当前可见区域中心为锚点，允许页容器内部横向滚动，不撑宽整个应用。
- 旁证返回：保存进入旁证前的一份锚点和知识点；连续查看多个引用不覆盖起点。用户主动翻页结束旁证状态。
- 若异步恢复期间用户又滚动或导航，以最新用户操作为准，作废旧恢复令牌。

右栏滚动位置按书籍/内容版本/知识点保存到会话状态；不能把上一知识点的底部位置套到新知识点。无有效位置时从顶部开始。

## 5. 讲解分层

核心解释默认可见，目标和必要证据不藏在折叠层中。公式与推导、图片详解、例子与实践、检查理解分别独立展开，允许并行打开，不使用只能开一项的手风琴。

每一块应有描述性标题，例如“为什么距离翻倍得到1/4”，不只叫“详细内容”。不强行生成空模块；无图解就不展示图片标题，无自测则不能显示虚构的测验入口。

旧课程迁移时以现有 sections/cards 的语义分组，保留全部原文和引用，不仅展示第一张卡。前置知识、推导与答案深浅分明；答案必须主动揭示。展开答案不自动标为掌握。

章节选择移入书籍目录或当前章节的知识点列表，删除全局固定的5.1/5.2/5.2.2按钮。此步骤依赖通用课程目录，不能仅把硬编码按钮藏进另一个组件。

问答改为次要的“查找相关内容”入口并标明实际检索范围。笔记作为后续独立能力，首批不展示不可用按钮。Shader仍使用外部编辑器与明确的复制/运行指引。

## 6. 无内容与故障

- 本页暂无精讲：一段短提示和继续阅读入口，不铺一屏警告；不展示无关课程。
- 页面未解析：原书正常显示，区域操作不可用；提示与精讲状态各说各的，不混淆。
- 解析失败/讲解失败：各自重试，不重载PDF；不要把损坏产物伪装为暂无内容。
- 侧栏收起时新错误不弹出侧栏抢焦点；展开后显示状态。
- 章节加载慢时显示当前位置的加载状态，不闪现上一节内容。

## 7. 状态与组件边界

- ReadingState：页码、缩放模式、区域选择、旁证返回锚点。单向事件驱动。
- WorkspaceState：宽屏侧栏开关、分栏比例、窄屏面板、目录开关。
- StudyState：知识点、展开组、答案草稿、自评。按内容身份隔离。

建议新增 ReadingWorkspace 负责壳层布局，workspaceState 负责纯状态转换，readingAnchor 负责几何换算；App 保留数据协调，不再堆入拖动事件与折叠DOM。

偏好存储使用版本化 localStorage，仅保存小型JSON。全局版面偏好与书籍阅读位置分key；当前只记录已知可靠的书籍ID，待书籍版本公开契约接入后迁移，不臆造版本。存储读取必须校验类型、范围及ID；存储被禁用或超限时退回内存。

不存PDF、页面图片、整段检索结果。答案草稿首批保证本会话收展不丢失；跨刷新草稿保存作为明确后续项，不在UI暗示已经提供。

## 8. 可访问性与视觉原则

- 开关用文字按钮并设置 aria-expanded、aria-controls；收起时把焦点交回可见开关。
- 内容使用语义details/summary或等价可访问结构；隐藏面板不可Tab到。
- 动画遵循 reduced-motion；首次实现不使用宽度过渡，以免PDF连续重渲染。
- 图标配文字或可访问名称；按钮不能仅靠颜色表达选中状态。
- 长公式和代码只在内容区域横向滚动，整个页面不溢出。
- 界面一处显示当前位置，不用重复的大标题、边框与说明挤占原书空间。

## 9. 分批验收

A：侧栏收展与学习状态保持；B：阅读锚点、分栏、窄屏与键盘；C：分层讲解与通用目录接入。每批独立测试/提交，不把界面壳层完成称为全书精讲完成。

必须实机验证：滚到PDF页中段→写入问题→展开推导→收起→展开，原文位置与草稿均保持；关闭伴读后翻页不弹出；跨页引用返回正确；窄屏原书/伴读切换不重载文档；刷新恢复版面偏好；localStorage失败仍可读；最后一页/未解析页同样可用。

测试覆盖：纯状态转换、归一化锚点边界、组件焦点/隐藏行为、异步竞态、内容展开状态以及实际PDF视觉定位。自动测试通过不能替代窄屏/缩放后的视觉对齐检查。
